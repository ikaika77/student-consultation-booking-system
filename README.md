# student-consultation-booking-system
A web-based system for managing consultation appointments between students and lecturers.

**Project Description**
The Student Consultation Booking System is a web-based system designed to simplify the process of scheduling consultation sessions between university students and lecturers. Students can view available consultation slots, submit booking requests, and manage their appointments. Lecturers can manage their availability and review, approve, or reject consultation requests. The system aims to reduce scheduling conflicts and improve consultation management.
